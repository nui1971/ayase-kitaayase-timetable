## アプリのアイデア・使い方

どんな場面で使うか：
綾瀬駅で北綾瀬駅へ行くの電車に乗り換える時に次の電車が何番線ホームｋら何分後発車かを確認するアプリ
| 項目 | 内容 |
|---|---|
| 誰が使うか | 自分（個人利用） |
| いつ使うか | 綾瀬駅で北綾瀬駅行きに乗り換え時 |
| 何のために使うか | 次の列車まで発車ホーム、何分かを素早く確認する |

一番重要なことは何か：
- 綾瀬駅で北綾瀬駅行きは0番線（綾瀬⇔北綾瀬）3,4番線（直通で北綾瀬行き）があり、ホームが異なる。
- 乗り換え時に素早く次の列車が何番線ホームかを確認したい。


表示したい情報は何か：
| エリア | 内容 |
|---|---|
| ヘッダー | C20バッジ・駅名（北綾瀬/Kita-Ayase）・現在時刻・日付 |
| ダイヤバッジ | 平日／土・休日（今日に対応する方をグリーン表示） |
| 次の列車カード | 何番線ホーム、時刻・種別・あとXX分 |
| 列車リスト | 何番線ホーム、時刻・種別・あとXX分　5本表示 |
- あとXX分は60分の場合はあと1時間、それ以上の場合はあとxx時間yy分と表示したい。
- 追加表示はいらない（5本の固定表示）

操作したいことは何か：情報の表示
不要・非表示にしたいものは：

その他・気になること：
- apiでODPT（公共交通オープンデータセンター）何番線ホームかがわかるのか？
- わからない場合、どうするかか
